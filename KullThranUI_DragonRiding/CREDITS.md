# Data credits

The Flight Master module includes data derived from these projects.

- Preset flight durations (`Modules/FlightMaster/FlightMaster_SeedData.lua`): Flight Timer Classic by Nomana (timohausmann), https://github.com/timohausmann/FlightTimerClassic, licensed under CC BY 2.0 (https://creativecommons.org/licenses/by/2.0/).
- Flight master spawn positions (`Modules/FlightMaster/FlightMaster_NPCData.lua`): CMaNGOS classic-db, https://github.com/cmangos/classic-db, licensed under GPL-3.0.
- Flight network and path lengths (`Modules/FlightMaster/FlightMaster_TaxiData.lua`): generated from the WoW Forever client tables TaxiNodes, TaxiPath and TaxiPathNode, read through wago.tools (https://wago.tools). World of Warcraft game data, (c) Blizzard Entertainment.
